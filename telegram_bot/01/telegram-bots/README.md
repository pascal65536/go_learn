## Структура проекта

```
telegram-bots/
├── main.go
└── utils/
    ├── dirty.go
    ├── file_json.go
    └── telegram.go
```

### Назначение файлов

- **main.go** — основной файл запуска бота, логика обработки обновлений и вызова хендлеров.
- **utils/telegram.go** — работа с Telegram API (отправка сообщений, получение апдейтов, webhooks и т.д.).
- **utils/file_json.go** — функции для чтения/записи JSON-файлов (например, для хранения обработанных update_id).
- **utils/dirty.go** — вспомогательные утилиты для работы с файлами и директориями (копирование, перемещение, SHA256, проверка существования и т.д.).

---

## Лишние файлы

**В текущей структуре нет явно лишних файлов** — все они могут быть полезны:

- Если вы используете работу с файлами (копирование, SHA256, и т.п.), то `dirty.go` оправдан.
- Если не используете эти функции (например, если бот не работает с файлами вне JSON-логики), можно удалить из `dirty.go` неиспользуемые функции или сам файл.

**Рекомендация:**  
- Проверьте, используете ли вы функции из `dirty.go` в коде бота. Если нет — файл можно удалить или оставить только нужные функции.
- Всё остальное используется для работы бота и его хранения состояния.

## Как запустить проект


   ```
   go mod init telegram-bots
   ```

1. **Создайте файл `.env`** в корне проекта и добавьте туда токен вашего Telegram-бота:
   ```
   TOKEN=ваш_токен_бота
   ```

2. **Установите зависимости**, если используете сторонние библиотеки (например, `github.com/joho/godotenv`):
   ```
   go mod tidy
   ```

3. **Соберите проект:**
   ```
   go build -o bot main.go
   ```

4. **Запустите:**
   ```
   ./bot
   ```
   или просто
   ```
   go run main.go
   ```

5. **Убедитесь, что в папке `data/` есть файл `update.json`** (или он создастся автоматически).

---

## Кратко

- Лишних файлов нет, если используются все функции. Если не используете работу с файлами (SHA256, копирование и т.д.), можно удалить `dirty.go`.
- Для запуска нужен `.env` с токеном, команда `go run main.go` или сборка через `go build`.
- Все остальные файлы нужны для работы с Telegram API и хранения состояния.
